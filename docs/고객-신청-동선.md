# 2026 하나가족수양회 신청 폼 — 고객 동선 (경우의 수)

> 소스 기준 정리 · Notion 붙여넣기용 · 작성 2026-06-18

---

## 0. 전체 흐름 한눈에

```
랜딩(수양회 정보 + 회비 안내 아코디언)
   └─ [신청하기] →  유형 선택
                       ├─ 개인 신청 → ②정보입력 → ③확인/제출 → 완료
                       └─ 단체 신청 → 인원선택(2~6명) → ②대표자정보 → ③일행추가 → ④확인/제출 → 완료
```

- **개인 신청 = 3스텝** (유형 → 정보 → 확인)
- **단체 신청 = 4스텝** (유형 → 대표자 → 일행 → 확인) + 인원 선택 단계

---

## 1. 진입 / 랜딩

| 항목 | 내용 |
|---|---|
| 첫 화면 | 수양회 정보 카드(일시·장소·강사·등록기간) |
| 회비 안내 | 아코디언으로 접힘 → 펼치면 부서별 회비표 + 다자녀 할인 안내 |
| 행동 | [신청하기] 클릭 → 유형 선택 화면 |

---

## 2. 유형 선택

| 선택 | 다음 단계 |
|---|---|
| **개인 신청** | 바로 정보입력(Step2)로 |
| **단체 신청** | 인원 선택(본인 포함 2~6명) → 정보입력(Step2)로 |

- 단체에서 인원 N 선택 시 → 일행 카드 (N-1)개가 자동 생성됨

---

## 3. 정보 입력 (대표자 / 신청자 공통) — 소속에 따른 분기

소속(부서) 선택이 **모든 분기의 핵심**입니다.

### 3-1. 소속별 분기표

| 소속(드롭다운) | 내부코드 | 숙박 | 비숙박 할인 | 셀번호 | 비고 |
|---|---|---|---|---|---|
| 3진 / 2진 / 1진 청년2부 | ADULT_A | **비숙박 기본**(숙박 선택 가능) | ✅ 2만원 | ✅(EM 포함) | "비숙박이 기본" 안내 |
| EM / 새가족(셀소속 전) | ADULT_A | 위와 동일 | ✅ | EM만 셀번호 / 새가족 없음 | |
| 대학부(UCM) / 1진 청년1부 | ADULT_B | **숙박 고정**(선택 불가) | ❌ | 청년1부만 셀번호 | UCM은 2007년생 체크 |
| 중고등부(YCM) | YCM | **숙박 고정** | ❌ | ❌ | |
| 초등부(조이랜드) | JOYLAND | 비숙박/숙박 선택 | ❌ | ❌ | |
| 유치부(40개월~미취학) | KINDER | 비숙박/숙박 선택 | ❌ | ❌ | |
| 베이비(13~39개월) | BABY_PAID | 비숙박/숙박 선택 | ❌ | ❌ | |
| 베이비(~12개월) | BABY_FREE | 선택 | ❌ | ❌ | **무료(0원)** |

### 3-2. 등록 유형 분기 (현재 날짜로 자동 결정)

| 오늘 날짜 | 자동 등록유형 | 화면에서 선택 가능한 버튼 |
|---|---|---|
| ~ 07.15 | 선등록(EARLY) | 선등록만 활성, 일반등록 비활성, 일일등록 항상 가능 |
| 07.16 ~ 07.24 | 일반등록(REGULAR) | 일반등록만 활성, 선등록 비활성 |
| 07.25 ~ | 현장등록(ONSITE) | ⚠️ **현장등록 버튼이 없음**(아래 엣지케이스 참고) |
| 직접 선택 | 일일등록(DAILY) | 항상 선택 가능 |

- **일일등록 선택 시**: 참석 날짜(7/25 또는 7/26) 필수 선택 + **숙박 강제 비숙박** + 가족실 초기화

### 3-3. 가족실 희망 분기

| 조건 | 가족실 항목 노출 |
|---|---|
| 단체 신청 **AND** 대표자가 숙박 | ✅ "희망/희망 안 함" 선택 노출 |
| 개인 신청 | ❌ (개인은 가족실 신청 불가) |
| 비숙박 / 일일등록 | ❌ |

- 가족실은 **대표자 한 명에게만** 있고, 그 단체 전체에 적용됨(일행 개별 신청 불가)
- 안내: 기본 1실 8인, 2~6인 가족실은 방당 2~4만원 추가, 준비팀 검토 후 개별 문자

### 3-4. UCM 2007년생 이하 체크 (다자녀용)

| 조건 | 체크박스 노출 |
|---|---|
| **단체 신청 AND 소속=대학부(UCM)** | ✅ "2007년생 이하입니다" |
| 개인 신청 | ❌ |

- 체크 시 → 다자녀 할인의 "자녀" 인원에 포함됨

## 4. 일행 추가 (단체만)

- 일행 카드마다 3장의 분기(소속·등록유형·숙박)를 동일하게 반복
- 일행은 **연락처 입력 없음**(대표자만 연락처)
- 일행 ≥ 2명일 때 다자녀 할인 안내 박스 노출

### 다자녀 할인 규칙

| 자녀 수(아래 기준) | 할인율 | 적용 대상 |
|---|---|---|
| 3명 이상 | 10% | 부모 + 자녀 전원 |
| 4명 이상 | 15% | 부모 + 자녀 전원 |

- **자녀 기준 부서**: YCM(중고등)·초등·유치·영아 + **UCM 중 2007년생 이하 체크자**
- ⚠️ 자녀 카운트는 **일행(companions)만** 셈 — 대표자는 자녀로 안 셈
- ⚠️ 개인 신청은 일행이 없어 다자녀 할인 불가 → **자녀 있는 가정은 반드시 단체로 신청해야 함**

## 5. 확인 / 제출

- 신청자(+일행) 정보 요약, 금액 내역, 다자녀 할인 표시, 총 입금액
- 입금 계좌(국민 632901-01-454842, 하나교회), 입금자명 = 신청자/대표자명
- "위 내용을 확인했습니다" 체크 → [신청 완료]
- 제출 → `/api/submit` → Google Apps Script → 시트 기록
- 완료 화면: 요약 + 입금 안내 + [추가 신청하기]
